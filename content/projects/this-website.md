The site you are reading. Every page is plain static HTML generated by
[Hugo](https://gohugo.io/), styled as the output of a shell command.

## How it works

- Pages are Markdown files; the theme is a handful of custom templates.
- Hugo also writes an `index.json` listing every page. The prompt reads it,
  so `ls`, `cd` and `cat` always match the real content.
- Without JavaScript the prompt disappears and the links keep working.
- It is built by GitHub Actions and hosted on GitHub Pages.

## How it was built

I built it with [Claude Code](https://claude.com/claude-code), an AI coding
agent. It wrote the templates, the stylesheet, the prompt script and the first
drafts of the text. I decided what to build, chose between the options,
changed direction when I did not like the result, and rewrote the parts that
had to sound like me.
